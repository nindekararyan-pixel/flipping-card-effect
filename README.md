# Developer Portfolio

A personal portfolio website built with vanilla HTML, CSS, and JavaScript — styled like a code editor (dark theme, monospace fonts, syntax-highlighted colors) instead of a typical template.

## 📂 Sections
- **Home** — landing/intro section
- **About** — background and bio
- **Skills** — flip cards revealing skill details on hover (HTML/CSS, JavaScript, Python, Problem Solving)
- **Projects** — showcase of past work
- **Contact** — code-editor styled contact form with live input validation

## ✨ Features
- Code-editor themed UI (tab bar, line numbers, syntax-highlight colors)
- Flip-card skill showcase using CSS 3D transforms (`perspective`, `preserve-3d`, `backface-visibility`)
- Contact form with real-time validation (name, email, subject, message) and terminal-style submit button
- Fully responsive layout (mobile-friendly, no horizontal scroll)
- Built with plain HTML/CSS/JS — no frameworks, no build step

## 🛠️ Tech Stack
- HTML5
- CSS3 (Grid, Flexbox, custom properties, animations & transitions)
- Vanilla JavaScript (form validation, DOM manipulation)
